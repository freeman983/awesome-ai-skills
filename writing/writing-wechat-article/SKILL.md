# 微信公众号文章写作

写出让人读完、转发、收藏的公众号文章。不是写作技巧的堆砌，而是对移动端阅读心理的深刻理解。

## 核心认知

### 公众号不是博客
- 读者在手机上阅读，拇指随时准备划走
- 平均阅读时长 3-5 分钟，超过 8 分钟流失率陡增
- 转发动机：让我显得有品味/有见识/有态度
- 打开率取决于标题，完读率取决于节奏

### 三秒定律
读者给你三秒钟：标题决定打开，首段决定留下，节奏决定读完。

## 标题工程

### 标题公式

| 类型 | 公式 | 示例 |
|------|------|------|
| **数字型** | [数字] + [主题] + [价值承诺] | "7 个让代码质量翻倍的习惯" |
| **悬念型** | [现象] + [反转/疑问] | "年薪百万的程序员，都在做这件'无聊'的事" |
| **痛点型** | [目标人群] + [痛点] + [解法暗示] | "总是写不完需求？问题可能不在效率" |
| **对比型** | [A] vs [B] + [洞察] | "初级和高级工程师的真正区别，不是技术" |
| **故事型** | [人物/事件] + [戏剧性结果] | "我用一个周末重写了整个后端，然后..." |

### 标题禁区
- ❌ 标题党（内容撑不起标题的承诺）
- ❌ 超过 30 字（手机显示截断）
- ❌ 生僻词或英文缩写（降低点击率）
- ❌ "震惊！""不转不是中国人"（平台降权）

### 副标题（摘要）
- 补充标题未说完的信息
- 15-20 字，一句话概括核心价值
- 出现在分享卡片中，影响二次传播

## 文章结构

### 开头（前 3 段 = 生死线）

**模式 1：场景代入**
```
你有没有过这种经历——
周一早上打开电脑，看着满屏的未读消息，突然觉得这份工作毫无意义。
别急着否认。这种感觉，比你想象的普遍得多。
```

**模式 2：反常识开场**
```
我要说一个可能得罪人的观点：
大多数人的"努力"，其实是在逃避思考。
```

**模式 3：数据冲击**
```
一个数据：中国程序员平均在一家公司待 18 个月。
不是因为他们浮躁，而是因为大多数公司不值得待更久。
```

**模式 4：故事钩子**
```
去年冬天，我做了一个决定——拒绝了一份薪资翻倍的 offer。
朋友说我疯了。半年后，他们改口了。
```

### 正文节奏

**黄金节奏：短-长-短-长**

```
[短段落：1-2 句，抛出观点]

[长段落：3-5 句，展开论证或讲故事]

[短段落：金句或转折]

[长段落：案例或数据支撑]
```

**段落规则**：
- 每段不超过 4 行（手机屏幕）
- 每 3-4 段插入一个"呼吸点"（金句/小标题/分割线）
- 重要观点单独成段，加粗

### 小标题设计

小标题是"第二次 hook"——读者扫读时的锚点。

```
✅ "为什么你的代码总是改不完"（痛点共鸣）
✅ "真正的解法，只有三步"（价值承诺）
❌ "第一部分"（毫无信息量）
❌ "关于效率的思考"（太抽象）
```

### 结尾

**模式 1：金句收束**
```
所有的捷径，最终都是弯路。
而所有看似的弯路，才是真正的捷径。
```

**模式 2：行动号召**
```
如果这篇文章对你有启发，试试今天就做一件事：
把你最重要的三个任务写下来，然后划掉两个。
```

**模式 3：开放式提问**
```
最后想问你一个问题：
如果明天就是你在这家公司的最后一天，你今天会做什么不同的事？
欢迎在评论区聊聊。
```

## 排版规范

### 移动端适配

| 元素 | 规范 |
|------|------|
| 正文字号 | 15-16px |
| 行间距 | 1.75-2 倍 |
| 段间距 | 空一行 |
| 每段长度 | ≤ 4 行（手机屏幕） |
| 全文长度 | 1500-3000 字（最佳） |
| 图片 | 每 500 字至少 1 张 |

### 视觉节奏工具

- **加粗**：核心观点（每段最多加粗一处）
- **引用块**：金句、数据、他人观点
- **分割线**：章节转换
- **列表**：并列信息（不超过 7 项）
- **小标题**：每 300-500 字一个

### 禁止事项
- ❌ 大段无分隔的文字墙
- ❌ 花哨的字体颜色（影响阅读）
- ❌ 过多 emoji（3-5 个/全文足够）
- ❌ 外链（公众号不支持外链跳转）

## 写作语感

### 口语化但不随意

```
✅ "说白了，就是把复杂的事情拆简单。"
✅ "你可能会问：这跟我有什么关系？"
❌ "综上所述，我们可以得出以下结论..."
❌ "笔者认为..."
```

### 节奏感

好的公众号文章读起来像说话，有停顿、有重音、有呼吸。

```
短句制造紧张。
长句展开叙述，让读者跟着你的思路走一段路，感受你想表达的完整意思。
然后，一个短句收住。
```

## 文章类型模板

### 干货型（教程/方法论）
```
标题：[数字] + [方法] + [效果]
开头：痛点场景 → "我也经历过" → "后来我找到了方法"
正文：方法 1（案例）→ 方法 2（案例）→ 方法 3（案例）
结尾：总结 + 行动建议
```

### 观点型（评论/思考）
```
标题：[反常识观点] 或 [现象 + 洞察]
开头：现象描述 → 大众认知 → "但我认为..."
正文：论点 → 论据 → 反驳可能的质疑 → 深化
结尾：升华 + 开放讨论
```

### 故事型（经历/案例）
```
标题：[人物/事件] + [戏剧性结果]
开头：故事高潮或结局（倒叙）
正文：回到起点 → 发展 → 冲突 → 转折 → 结局
结尾：从故事中提炼的普适道理
```

## 传播优化

### 转发心理学
人们转发是因为：
1. **社交货币** — "看，我知道这个"
2. **实用价值** — "这个对你有用"
3. **情感共鸣** — "这说的就是我"
4. **身份认同** — "这代表我的态度"

### 引导互动
- 文末提问（具体的、容易回答的）
- "你觉得呢？" 不如 "你遇到过类似的情况吗？"
- 评论区置顶一条引导性评论

## 快速检查清单

1. 标题能让人在朋友圈停下拇指？
2. 前三段能留住读者？
3. 每段不超过手机屏幕 4 行？
4. 每 300-500 字有小标题或视觉锚点？
5. 读起来像说话，不像论文？
6. 结尾有明确的情感落点或行动指引？
7. 读者转发时，会觉得"有面子"？
